# Secure Enterprise Infrastructure Lab

## Project Overview

This project simulates the deployment, administration, networking, automation, and security hardening of a small enterprise infrastructure using Red Hat Enterprise Linux.

## Objectives

- Linux Administration
- User and Group Management
- File Permissions and Ownership
- Networking and Routing
- Firewall Configuration
- SELinux Security
- System Hardening
- Python Automation
- Bash Automation
- Git & GitHub Documentation
- Security Assessment and Evidence Collection

## Technologies

- Red Hat Enterprise Linux 9.4
- Kali Linux
- VMware Workstation
- Python
- Bash
- Git
- GitHub
- NetworkManager
- firewalld
- SELinux

## Completed Work

### Linux Administration
Documentation covering users, groups, permissions, ownership, and sudo access.

### Networking
Network assessment covering interfaces, routing, gateway connectivity, Internet connectivity, and DNS resolution.

### Python Automation
Documentation covering Python basics, file handling, and automation concepts.

### Security
Security documentation and practical assessment covering sudo, firewalld, SSH, and SELinux.

### Automation
Bash system-check script for collecting system, network, connectivity, and DNS information.

### Reports
Project assessment report documenting the current project status and completed components.

## Current Status

The project documentation, networking assessment, security assessment, and initial automation components are complete.

Final repository review and evidence organization remain.
