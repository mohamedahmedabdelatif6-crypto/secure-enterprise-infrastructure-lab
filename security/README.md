# Security

## Objective

Practice basic security administration and hardening techniques in Red Hat Enterprise Linux.

## Topics

- User and group security
- File permissions
- Ownership
- sudo access
- Firewall configuration
- SELinux
- Security auditing
- System hardening

## Basic Commands

Check file permissions and ownership:

```bash
ls -l
```
Check the current user:

```bash
whoami
```
Check sudo privileges:

```bash
sudo -l
```
Check firewall status:

```bash
sudo firewall-cmd --state
```
Check SELinux status:

```bash
getenforce
```
## Result 

Security administration helps protect Linux systems by controlling access, enforcing permissions, managing network services, and applying system hardening practices.
